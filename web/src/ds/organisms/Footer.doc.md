# Footer

## Level
Organism.

## Replaces
The public footer in `SiteLayout.tsx`. Looks the same as today.

## Use it for
- Wordmark, one line, link columns, and the method line with the page date.

## Versions
One.

## Access
- Links are 44 px tall and the headings are not links.
- `paper-dim` and `muted` on `void` are above 4.5:1.

## Do and don't
- Do pass links as nodes, so the router stays with the page.
- Don't add a fourth column on a phone: two columns, brand on top.

## Live example
`Footer.example.tsx`, at `/admin/design`.
