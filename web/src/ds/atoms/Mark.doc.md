# Mark

The wheel, its horizon line and the Ascendant as a brass point on the left (logo spec).

## Props
- `className` sets the size and the ring colour (`currentColor`); `point` is brass by default; `title` makes it an image, otherwise it is hidden from readers.

## Don't
- Redraw it, add a gradient or a glow, or recolour the point.

## Versions today and after
20 px in a bar, 64 px for big moments. The paths are today's, unchanged. `components/Mark.tsx` re-exports this part.
